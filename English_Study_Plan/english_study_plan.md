# 海淀初二英语三周单词突击计划 (每天1小时)

**目标对象**：北京海淀初二学生（面临中考压力，基础较弱）
**核心目标**：快速积累核心词汇，建立信心，养成高效背词习惯。
**时间投入**：每天1小时（建议分割为：早20分钟 + 晚40分钟）

---

## 一、 核心方法论 (Methodology)

针对海淀区通过“题海”和“高标准”要求的特点，但孩子目前基础较弱，**不能死记硬背**，否则容易产生厌学情绪。我们采用 **“333法则”**：

1. **30% APP/词表快速刷词**：利用碎片时间，混个脸熟。
2. **30% 语境阅读**：在句子和短文中理解单词，这是海淀考题的核心（完形填空、阅读理解）。
3. **30% 听写与拼写**：动笔写，落实到纸面上。
4. **10% 复习 (艾宾浩斯)**：对抗遗忘。

---

## 二、 推荐资料 (Resources)

### 1. 核心词汇书 (必选)

* **[北京中考21天核心词汇清单](./beijing_zhongkao_vocab_21days.md)** (我为您专门定制的每日背诵表)
* **《北京中考英语 1600 词》** (或者任何一本针对北京中考的词汇书)。
  * *理由*：初二下学期马上进入初三中考备战，海淀的进度通常较快。直接从“中考高频词”入手性价比最高。
* **“百词斩” 或 “不背单词” APP**
  * *理由*：利用图像和声音辅助记忆，降低枯燥感。设置目标为“北京中考”词库。

### 2. 配套阅读/教材 (二选一)

* **方案 A (经典稳重)**：《新概念英语 2》 (New Concept English 2)
  * *用法*：不求全文背诵，但求核心课文的单词能听写，句子能翻译。
* **方案 B (兴趣驱动)**：《书虫·牛津英汉双语读物》 (2级或3级) 或 《黑布林英语阅读》
  * *理由*：如果孩子极其排斥教科书，用故事书切入。

### 3. 辅助工具

* **A4纸折叠法**：将A4纸对折，左边写英文，右边写中文，反复自测。
* **错题/生词本**：极其重要。

## 三、 三周详细计划 (3-Week Schedule)

### 准备工作 (Day 0)

* 下载APP，选择“北京中考”词库。
* 准备好《中考词汇书》和一本笔记本。
* **约定奖励**：如果坚持完三周，给予一个具体的奖励 (Positive Reinforcement)。

### 第一周：高频动词与形容词突破 (唤醒语感)

**重点**：动词是句子的骨架，形容词是阅读情感的色彩。先攻克这些最常用的词。

| 时间段 | 内容 | 具体执行 |
| :--- | :--- | :--- |
| **早晨 (20min)** | **APP刷词** | 设定每日新词20个，复习30个。利用早餐或上学路途时间。重点听发音，跟读。 |
| **晚上 (30min)** | **课内/阅读材料** | 拿出英语教材或新概念2。**精读1篇课文**。不是看过去，而是把不认识的单词圈出来，查字典，**造一个句子**。 |
| **晚上 (10min)** | **A4纸自测** | 将今天遇到的生词整理到A4纸上。遮住中文看英文，遮住英文写中文。**写不出来的词画圈，明天重点复习。** |

* **周末任务**：复习本周所有“画圈”的错词。做一张往年中考英语的“单项选择”或“完形填空”专项练习（只做1篇），检验单词认读情况。

### 第二周：名词分类与阅读实战 (巩固提升)

**重点**：分类记忆名词（生活、学校、自然等），开始介入“阅读理解”训练。

| 时间段 | 内容 | 具体执行 |
| :--- | :--- | :--- |
| **早晨 (20min)** | **APP刷词** | 每日新词25个，复习40个。保持对上一周词汇的复现。 |
| **晚上 (30min)** | **中考真题阅读** | 找北京近3年的中考（或海淀区期末题）阅读理解A篇和B篇（相对简单）。**不求做对题，只求读懂文章。** 把文章里不认识的词全部抠出来。 |
| **晚上 (10min)** | **听写测试** | 家长报中文，孩子写英文。或者使用APP的听写功能。错误率超过20%则罚抄（不用多，抄3遍即可，关键是过脑子）。 |

* **周末任务**：整理“阅读高频词”。你会发现很多词在不同的文章里反复出现，这些就是“核心词汇”。

### 第三周：短语搭配与综合运用 (冲刺)

**重点**：单词不是孤立的。重点攻克固定搭配 (Collocations) 和介词短语。

| 时间段 | 内容 | 具体执行 |
| :--- | :--- | :--- |
| **早晨 (20min)** | **短语背诵** | 重点背诵 `take off`, `look forward to`, `get used to` 这类中考必考短语。 |
| **晚上 (30min)** | **完形填空专项** | 完形填空是海淀考题中词汇辨析最难的部分。每天做1篇完形填空。**分析每一个选项**，为什么选A不选B？ |
| **晚上 (10min)** | **复盘与清理** | 翻看前两周的生词本。把已经滚瓜烂熟的词划掉（获得成就感），把依然记不住的“钉子户”抄到一张新的“终极小抄”上。 |

* **周末总结**：进行一次全真模拟小测验（30分钟），包含本周背诵的单词和短语。

## 四、 给家长的建议 (Parental Guidance)

1. **不要只盯着“背了多少个”**：要关注“认出了多少个”。阅读中认识单词比死记硬背拼写更重要（对于初二阶段）。
2. **创造环境**：如果可能，家里贴一些便利贴（比如冰箱 fridge, 微波炉 microwave），让单词生活化。
3. **少批评，多鼓励**：基础差的孩子最怕打击。只要她今天坚持了1小时，无论记住多少，都应给予肯定。
4. **海淀特色**：海淀的考试阅读量大。建议这三周内，尽量让孩子多“读”英文（出声读），建立语感对做题帮助极大。
